# 🍔 Card-pio — Sistema de Pedidos de Hamburgueria

Sistema de pedidos via terminal desenvolvido em Python.

## Funcionalidades
- Cardápio com hambúrgueres, refrigerantes e molhos
- Suporte a múltiplos itens por categoria
- Cálculo de frete por região
- Desconto de 10% em pedidos acima de R$ 50
- Resumo detalhado do pedido

## Como executar
```bash
python Cardapio.py
```

## Tecnologias
- Python 3.10+
